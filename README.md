# Slothoth's Civ VI Modding Guide

This guide is meant to be a one stop-shop for all people wanting to get involved with modding in Civ VI (and Civ VII, once I write it).

I am accepting contributions, so happy for people to write chapters about their niche specialties, and I will have a look through to make sure it makes sense, make any corrections, get back to you that those correcrions are fine, and if so publish, with credit given.

To make things easiest, doing a github Pull Request would be ideal, adding your content as a Markdown file under the content/ folder. To navigate the repo yourself locally in edit mode, you can just open the Contents folder as an [Obsidian](https://obsidian.md/) Vault.

If you are less technical, you can also just PM me your chapter on Discord, you can find me at the Civ VI Modding Helpline, or the VII one, or the official Civ Discord as Slothoth.
