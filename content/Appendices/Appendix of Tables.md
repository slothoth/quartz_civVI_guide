There are over 400 SQL tables defined in the database, with all DLC and modes on. As a result, it would very impractical to detail all of them, especially as a lot of them are rather obvious. However, it can be very useful to search columns of various tables to try find what controls a given feature, like what makes it so the Oppidum can fire ranged attacks on units? Districts_XP2.AttackRange of course. Here is a full chart of all of the tables. As you can see, its wayyy too big to even really understand just from this document, but it can be useful in other formats. In the Documents file, you can download the file DebugGameplay_hierarchical.svg and open it in a web browser, probably just with a double click. You can then ctrl-F to search for certain text, like District. Thats how i found the Oppidum effect. ![[DebugGameplay_hierarchical.svg]]

This was generated using the Database viewer of Dbeaver, exporting to GraphML format, then loading that into the online tool [yED](https://www.yworks.com/yed-live/), then exporting as SVG, with a few tweaks to colour of the text using Inkscape.
