# VS Code Library
https://marketplace.visualstudio.com/items?itemName=WildW.vscode-civvi-environment
or at:
https://github.com/Wild-W/vscode-civVI-environment

This tool lets you get auto-completion for writing Lua code, specifically for the special objects and variables defined in the Civ VI environment. If you personally don't like VSCode, you can get the same effect by just including the folder in the github link at [*vscode-civVI-environment/civ_library/CivilizationVI/library*](https://github.com/Wild-W/vscode-civVI-environment/tree/master/civ_library/CivilizationVI) in your project, and any code editor worth its salt will allow autocompletion.
