# Debugging
You cannot change how the game loads a .modinfo file once you have launched the game.  You can however, change the contents of the files it references, like editing an SQL file. This is useful for debugging faster, and saving time relaunching the game.

I highly recommend the Quick Start mod, that removes the initial promotional screens and shortens launch time.
