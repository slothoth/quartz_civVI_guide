# Firetuner
Firetuner is a tool that comes with the Civ VI development kit that allows you to view valuable information while debugging, and grants access to cheats to manipulate a game to allow testing your mods effects. It also provides a Lua console where you can query the current state of various Lua files, execute functions and code.
